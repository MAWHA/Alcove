## 为什么 `Exception-handling.json` 不单独建模块

旧版里它被 6 个文件用 `[JumpBack]Exception-handling-*` 引用，本质是「随时可能弹出的杂项弹窗」。
在新架构里这类东西用不着图结构，直接做成一个可复用的步骤函数：

```python
ctx.scan(干正事, handle_exceptions, timeout=30_000)
```

`handle_exceptions` 会按 `EXCEPTION_CANDS` 里的 5 个候选项各看一眼，弹了就点掉，没弹就当无事发生。
