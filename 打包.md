# Alcove 项目打包指南

## 当前项目状态
- 使用 `uv` 管理依赖
- 无完整的打包配置
- 包含大量资源文件（`assets/` 目录）

## 完整打包配置

### 1. 更新 `pyproject.toml`

```toml

[project]
name = "alcove"
version = "0.1.0"

readme = "README.md"

    {name = "Your Name", email = "your.email@example.com"}

classifiers = [
    "Programming Language :: Python :: 3",
    "Programming Language :: Python :: 3.13",

    "License :: OSI Approved :: MIT License",
    "Topic :: Games/Entertainment",

    "maafw>=4.5.6",
    "pyyaml>=6.0.3",

[project.scripts]

[tool.setuptools]
packages = [
    "MWATools",
    "PyPipeline",
    "PyPipeline.CustomActions",
    "PyPipeline.CustomRecos",
]

[tool.setuptools.package-dir]

[tool.setuptools.package-data]
"*" = ["*.json", "*.yaml", "*.yml"]
"MWATools" = ["*.pyi", "py.typed"]

[tool.setuptools.data-files]
"share/alcove/assets" = ["assets/**/*"]
"share/alcove/config" = ["config/**/*"]
```

### 3. 更新 `main.py` 添加入口函数

```python
# 在文件末尾添加
def main():
    # 现有的 __main__ 代码
    try:
        pipeline_override = {
            "MyCustomEntry": {"action": "custom", "custom_action": "StartApp"},
        }
        MWAController = MWAControllerClass()
        MWAController.load_controller()
        MWAController.choose_adb_controller()

        MWATasker = MWATaskerClass()

        adb_controller = MWAController.connect_adb_controller()
        MWATasker.MWATaskerBind(controller=adb_controller, resource=MWAResource.resource)
        # task_detail = MWATasker.run_action("MyCustomEntry", pipeline_override)
        reco_pipeline_override = {
            "MyCustomReco": {"recognition":"custom", "custom_recognition":"PopUpRecognition"},
        }
        reco_detail = MWATasker.run_custom_recognition("MyCustomEntry", pipeline_override=pipeline_override)
        print("识别结果：", reco_detail)
    except KeyboardInterrupt:
        print("\n检测到Ctrl+C，程序将取消并退出")
        MWATasker.Tasker.stopping()

if __name__ == '__main__':
    main()
```

## 构建命令

```bash
# 安装构建工具
uv add --dev build

# 构建分发包
python -m build

# 或使用 uv
uv build

# 构建产物在 dist/ 目录
# alcove-0.1.0-py3-none-any.whl
# alcove-0.1.0.tar.gz
```

## 安装方式

### 1. 本地安装
```bash
# 从源码安装
pip install .

# 或使用 uv
uv pip install .

# 从构建的 wheel 安装
pip install dist/alcove-0.1.0-py3-none-any.whl
```

### 2. 使用安装后的程序
```bash
# 直接运行（通过 entry point）
alcove
```

## 高级打包选项

### 1. 打包为独立可执行文件（PyInstaller）
```bash
# 安装 PyInstaller
uv add --dev pyinstaller

# 创建 spec 文件
pyi-makespec --onefile --console main.py

# 修改 spec 文件包含资源
# 在 Analysis 部分添加：
# datas=[('assets', 'assets'), ('config', 'config')],

# 构建
pyinstaller main.spec
```

### 2. Docker 容器化
```dockerfile
# Dockerfile
FROM python:3.13-slim
WORKDIR /app
COPY . .
RUN pip install .
CMD ["alcove"]
```

## 注意事项

1. **资源文件路径**：打包后资源文件路径会变化，需要修改代码中路径查找逻辑
2. **配置文件**：考虑用户可覆盖的配置目录（如 `~/.config/alcove/`）
3. **平台特定**：MAA框架可能有平台特定依赖
4. **版本管理**：使用 `setuptools_scm` 自动管理版本

## 验证打包
```bash
# 创建测试虚拟环境
uv venv test_env
test_env\Scripts\activate  # Windows
source test_env/bin/activate  # Linux/macOS

# 安装并测试
pip install dist/alcove-0.1.0-py3-none-any.whl
alcove --help
```

选择哪种打包方式取决于分发目标：
- **Python包**：适合开发者、与其他Python项目集成
- **可执行文件**：适合最终用户，无需安装Python环境
- **Docker容器**：适合部署到服务器环境
